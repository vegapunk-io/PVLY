Remove metadata & Content Credentials

Metadata strip for JPEG, PNG, WebP, PDF and DOCX: EXIF, XMP, IPTC, comments, PNG text chunks, PDF document properties/attachments, Word author/company/tracked-change data and C2PA/JUMBF manifests are removed, then the output is re-scanned to prove what is gone. Embedded statistical watermarks are not removed.

Drop a file here, or choose one below.
JPEG · PNG · WebP · PDF · DOCX · up to 200 MB

What gets removed

JPEGAPP1 EXIF/XMP, APP11 JUMBF (C2PA), APP13 IPTC/Photoshop, COM comments
PNGtEXt / zTXt / iTXt, eXIf, C2PA caBX chunk
WebPEXIF, XMP, ICCP (optional), C2PA chunk; VP8X flags cleared
PDFInfo dictionary, XMP metadata, embedded attachments, C2PA; password-protected PDFs are rejected
DOCXAuthor/company/core properties, comments, tracked changes, custom parts, embedded image metadata; legacy .doc unsupported

Image pixels are untouched by default — only container metadata is cut. Enable re-encode to bake in EXIF orientation at the cost of a lossy re-save. PDF/DOCX are rewritten structurally (not byte-lossless).

Honest limits

Metadata and C2PA are removable. Statistical watermarks (AudioSeal, VideoSeal, SynthID, DWT-DCT) are not — this tool never claims to remove them.
