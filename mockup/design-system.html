Layout & graphics

  • Grid: 1180px wrap, 20px gutters; grid2/grid3/grid4 collapse ≤900/680px. Sticky 58px nav.
  • Graphics: inline SVG stroke icons & the check mark only — no stock photos, no decorative shadows, no gradients (flat). Data visuals = tables, tags, progress bars, before/after diffs.
  • Radius: 10px cards / 7px controls (evolved from v0 sharp corners).
  • Motion: indeterminate progress only; respects prefers-reduced-motion.
  • A11y: focus = 2px orange outline; grade shown as text + color; semantic landmarks; dropzone always has input fallback.
